# ADR 005: Localized records, not locale columns

**Status:** accepted

Mandy's V0.1 supports `pt-PT`, `pt-BR`, `en` and `es`.

Localized restaurant content is modeled through translation records keyed by locale instead of columns such as `name_pt`, `name_en` and `name_es`. Adding another locale therefore does not require changing every content table.

User interface language is a user preference. Storefront languages are tenant-configurable and independent of the employee using the backoffice.
