# Mandy's V0.1

## Included

- Multi-tenant organization model.
- `pt-PT`, `pt-BR`, `en` and `es` as first-class locales.
- User language preference and tenant storefront locale configuration.
- Mandy's Minimal theme and theme entitlement model.
- Installable responsive backoffice PWA.
- Restaurant and location profile.
- Opening hours.
- Menu CMS with translated names/descriptions and allergens.
- Dining areas and tables.
- Customers.
- Reservations and reservation states.
- Group/event leads.
- Audit log foundation.
- Public storefront and direct reservation experience.

## Designed but not shipped in V0.1

- Online orders and payments.
- Inventory, recipes, purchasing and suppliers.
- Loyalty.
- Advanced analytics.
- Mandy's AI.
- Multi-location operational dashboards.
- Offline private data mutations.

These capabilities remain separate module entitlements so they can be added without changing the core tenant model.
