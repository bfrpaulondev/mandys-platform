# Mandy's V0.1 operations checkpoint

This checkpoint completes the initial restaurant setup surface needed for a usable V0.1 backoffice.

## Included

- authenticated global Backoffice navigation
- owner/manager operational settings
- opening hours for all seven weekdays
- dining area creation
- restaurant table creation with minimum and maximum seating
- tenant-scoped runtime access through a same-origin Backoffice gateway
- audit events for hours, dining areas and tables

## Runtime and isolation

Operational requests are authenticated with the existing Mandy's Better Auth session, resolved to the active organization and executed only after setting `app.organization_id` for the transaction. Existing RLS policies on opening hours, dining areas and restaurant tables remain defense in depth.

## V0.1 acceptance relevance

A restaurant owner can now progress from account and restaurant onboarding into the operational configuration needed before managing menus, reservations and events. The final V0.1 gate remains deployed browser E2E on the Backoffice and public Storefront.
